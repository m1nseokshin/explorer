# EXPLORER — 별로 길을 찾다

옛날 항해사들은 육분의로 별의 높이를 재서 자기 위치를 알아냈습니다.
**그 계산을 거꾸로 뒤집었습니다** — 어디 계신지 알려주시면, 그 자리의 하늘을 그려 드립니다.
그림이 아니라, 지금 고개를 들면 거기 있는 별로.

그리고 육분의 대신 **손**을 씁니다. 카메라 앞에서 손을 저으면 하늘이 그쪽으로 돌아가고,
펼치면 다가가고, 주먹을 쥐면 물러납니다.

## 손동작

| 제스처 | 동작 |
|---|---|
| 손바닥 펼침 · **정지** | 줌 인 |
| 손바닥 펼침 · **훽훽** | 상하좌우 둘러보기 |
| 주먹 | 줌 아웃 |
| 핀치 (엄지+검지) | 조준선 안의 별·별자리 선택 |

'펼친 채 정지'와 '펼친 채 훽훽'은 같은 손 모양이고 **속도로 구분**합니다. 다섯 번째
손 모양을 만들거나 모드 전환 버튼을 두는 것보다 낫습니다 — 창밖을 볼 때 사람이 이미
그렇게 행동하기 때문입니다. 경계에서 덜덜 떨리지 않게 히스테리시스를 넣었습니다
(팬 진입 0.35, 이탈 0.18).

**카메라 영상은 화면에 절대 표시하지 않습니다.** 인식된 손을 스켈레톤 선으로만 그립니다.
그것만으로 "지금 내 손이 잡히고 있다"는 확인은 충분하고, 사용자가 요청하지도 않은
자기 방 모습을 화면에 띄울 이유가 없습니다. 영상은 전부 기기 안에서 처리되며 어디로도
전송되지 않습니다.

손 인식이 안 되면(권한 거부, 다른 앱이 카메라 점유, HTTP 접속 등) **드래그와 휠**로
똑같이 둘러볼 수 있습니다. 어떤 실패 경로에서도 막다른 길이 되지 않습니다.

## 무엇이 들어 있나

- **위치부터 묻습니다** — 같은 시각이라도 서울과 시드니는 완전히 다른 별을 봅니다.
  그래서 위치는 설정 항목이 아니라 시작 단계이며, 지도로 먼저 보여줍니다.
  타일 서버를 쓰지 않아 **API 키도 외부 요청도 없습니다**.
- **지도** — 휠·핀치·버튼으로 ×1~×24 확대, 좌우로 계속 미는 무한 스크롤, 146개
  도시의 지명 표기(확대할수록 늘어남), 그리고 축척 막대.
- **홈 인터랙션** — 화면을 누르면 초신성이 터지고 그 자리에 별이 남습니다.
  간간이 유성이 떨어집니다. 전부 선으로만 그립니다(그라디언트 없음).
- **실제 하늘** — 관측 위치와 시각으로 세차·장동·지방항성시·광행차를 계산합니다.
  화면 속 하늘은 지금 고개를 들면 보이는 바로 그 하늘입니다.
- **8,874개의 별** — 맨눈 한계인 6.5등급까지. 등급에 따라 크기·밝기·광휘 반경이
  함께 달라지고, 1등성에는 아주 옅은 회절 십자가 붙습니다.
- **은하수** — 4만 8천 개의 흐린 점으로 그립니다. 채워진 면이 아니라 알갱이인
  이유는 실제 은하수가 분해되지 않은 별들의 집합이기 때문입니다.
- **88개 별자리 전부에 설명** — 유래와 무엇을 그린 것인지, 그리고 구성 별 목록.
  면적·순위·관측 적기는 하드코딩이 아니라 데이터에서 계산합니다.
- **완전 오프라인** — 성표도, 지도도, 손 인식 모델도, WASM도 전부 자체 호스팅입니다.
  외부 API를 한 번도 부르지 않습니다.

## 시작하기

```bash
npm install
npm run dev
```

`http://localhost:3000` 은 보안 컨텍스트로 인정되므로 카메라가 바로 동작합니다.
다른 기기에서 접속하려면 아래 **HTTPS** 절을 보세요.

### 데이터 재생성

`public/data/*`는 저장소에 커밋돼 있어 평소엔 필요 없습니다. 다시 만들려면
`data-src/`에 원본을 받은 뒤:

```bash
npm run data && npm run verify
```

원본은 [d3-celestial](https://github.com/ofrohn/d3-celestial)의 `data/`에서
`stars.8.json`, `starnames.json`, `constellations.json`(→`cons.json`),
`constellations.lines.json`(→`lines.json`), `constellations.borders.json`(→`borders.json`)
를 내려받으면 됩니다. `data-src/`는 gitignore 대상입니다.

### 손 인식 자산

`public/models/hand_landmarker.task`(7.8MB)와 `public/mediapipe/wasm/*`(12MB)는 CDN이
아니라 저장소에서 서빙합니다. 오프라인에서 동작하고, GitHub Pages basePath에서도
`asset()`을 통과해 경로가 깨지지 않습니다. 갱신하려면:

```bash
cp node_modules/@mediapipe/tasks-vision/wasm/vision_wasm_internal.* public/mediapipe/wasm/
curl -L -o public/models/hand_landmarker.task \
  https://storage.googleapis.com/mediapipe-models/hand_landmarker/hand_landmarker/float16/1/hand_landmarker.task
```

SIMD 미지원 폴백(`vision_wasm_nosimd_internal.*`)은 일부러 뺐습니다. 저장소가 11MB
가벼워지고, WASM SIMD가 없는 브라우저(Safari 16.4 미만 등)는 어차피 실시간 손 인식을
돌릴 성능이 안 됩니다. 그런 환경에서는 모델 로드가 실패하고 드래그 폴백 카드로 넘어갑니다.

## 다른 기기에서 열기 — HTTPS

`getUserMedia`는 보안 컨텍스트를 요구합니다. `http://localhost`는 인정되지만
**`http://192.168.x.x:3000`은 아닙니다.** 평범한 LAN HTTP로는 손 인식이 켜지지 않습니다.

**권장 — 터널:**

```bash
npx cloudflared tunnel --url http://localhost:3000
```

진짜 신뢰되는 공개 HTTPS URL이 나오고, 인증서 설치가 필요 없습니다.

**대안 — mkcert로 LAN IP 인증서:** `next dev --experimental-https`는 `localhost`
인증서만 만들어 다른 기기에는 도움이 안 됩니다. 대신:

```bash
mkcert -install && mkcert 192.168.0.10 localhost
```

그 뒤 해당 기기에 mkcert 루트 CA를 설치합니다. iOS는 프로파일 설치 후
**설정 → 일반 → 정보 → 인증서 신뢰 설정**에서 완전 신뢰를 따로 켜야 합니다.

## 검증

```bash
npm run verify
```

브라우저도 카메라도 없이 **293개 검사**를 돕니다.

### 천문 (276개) — `scripts/verify-sky.mjs`

1. **Polaris 고도 ≈ 관측지 위도** — 위도 5개 × 경도 3개 × 시각 6개. 행렬 전치,
   lat/lon 뒤바뀜, 부호 오류를 한 번에 잡습니다.
2. **독립 경로 교차검증** — `skyMatrix` 경로와 `astronomy-engine`의 `Horizon()`
   경로를 0.01° 이내로 대조합니다. 두 경로는 코드를 전혀 공유하지 않습니다.
3. **별자리 소속 일치** — 별자리선이 참조하는 모든 별에 대해 IAU 경계 기준 소속을
   확인합니다. 스냅 오류와 RA 단위 실수를 88개 별자리 전체에 대해 잡아냅니다.
4. **RA 단위 회귀** — 시간↔도 혼동은 하늘을 15배 회전시키지만 화면은 그럴듯해 보입니다.

추가로 은하수 점구름(은하 중심 부근 밀도), 별자리 면적(88개 합 = 41,253 제곱도),
관측 적기, 세계 지도 데이터의 무결성을 검사합니다. 면적 검산은 실제로 버그를
잡았습니다 — 극을 감싸는 작은곰자리·팔분의자리만 여집합 면적이 나와 20,000
제곱도로 계산되고 있었고, 뱀자리가 두 조각으로 중복 집계되고 있었습니다.

### 제스처 (17개) — `scripts/verify-gestures.mjs`

관절 3개짜리 사슬로 합성한 손을 넣어 판정 규칙을 잠급니다. 카메라 없이 돌아갑니다.

- **손 크기 척도가 제스처와 무관** — 손목→중지 MCP 거리를 씁니다. 손가락 길이를 쓰면
  주먹을 쥘 때 척도가 같이 줄어 판정이 무너집니다.
- **카메라 거리 무관** — 손이 두 배 가까워도 같은 제스처로 읽혀야 합니다.
- **핀치 히스테리시스** — 붙일 때 0.42, 뗄 때 0.62. 같은 값이면 경계에서 덜덜 떨립니다.
- **손바닥 중심 안정성** — 손가락을 다 접어도 중심이 움직이지 않아야 팬이 안 떨립니다.
- **데드밴드** — 반쯤 접은 손은 펼침도 주먹도 아니어야 합니다.

임계값을 만졌다면 `CURVE=1 node --experimental-strip-types scripts/verify-gestures.mjs`로
curl→openness 곡선을 직접 볼 수 있습니다.

## 조용히 틀리기 쉬운 지점

만들면서 실제로 밟은 함정들입니다. 자세한 목록은 `AGENTS.md`에 있습니다.

- **타입 티어는 `@layer components` 안에** — 아니면 Tailwind의 `text-*`가 통째로
  무시되는데, clamp()가 그럴듯한 크기를 내놔서 한참 눈치채지 못합니다.
- **이펙트 의존성에 인라인 콜백 금지** — 부모가 리렌더될 때마다 이벤트 리스너가
  다시 붙고, 드래그 중이면 그 순간 이동량을 잃습니다. "잡고 끌어도 조금만
  움직인다"의 원인은 좌표 계산이 아니었습니다.
- **극을 감싸는 별자리** — 사다리꼴 적분이 여집합 면적을 줍니다. 88개 합계
  검산(41,253 제곱도)이 없었다면 그냥 지나쳤을 오류입니다.
- **`backdrop-blur`는 보일 때만** — 95% 불투명 패널의 블러는 눈에 안 보이면서
  p95 프레임을 6ms 늘렸습니다.

## 알려진 한계

- **손 인식은 조명에 민감합니다.** 역광이거나 아주 어두우면 랜드마크가 끊깁니다.
  스켈레톤이 사라지는 것으로 바로 알 수 있고, 그때는 드래그 폴백을 쓰면 됩니다.
- **한 손만 인식합니다.** 두 손을 켜면 인식 부하가 두 배가 되고, 지금 제스처 어휘에는
  한 손이면 충분합니다.
- **대기굴절을 넣지 않았습니다.** 하늘 전체를 강체 회전시키는 구조상 고도에 따라
  비선형으로 변하는 굴절을 적용할 수 없습니다. 지평선의 별이 약 0.5° 낮게 그려집니다.
- **고유운동·연주시차를 생략했습니다.** 세기당 1초각 미만이라 무의미합니다.
- **iframe에 넣으면 카메라가 막힙니다.** 정적 내보내기라 `Permissions-Policy` 헤더를
  보낼 수 없습니다. 최상위 페이지로 열면 브라우저 기본값(`self`)이 맞게 동작하지만,
  다른 페이지가 이 사이트를 iframe으로 품는다면 그쪽에서 `allow="camera"`를 붙여야 합니다.
- **모델이 7.8MB입니다.** 첫 진입에서 한 번 내려받고 이후 캐시됩니다. 손 인식을
  시작할 때만 로드하므로 홈 화면에는 영향이 없습니다.

## 데이터 출처와 라이선스

별 위치·등급·색지수, 별자리 선과 IAU 경계, 별 이름은 모두
[**d3-celestial**](https://github.com/ofrohn/d3-celestial) (BSD-3-Clause,
© 2015–2019 Olaf Frohn)에서 파생됐습니다. 원본 성표는 Hipparcos와 Yale Bright
Star Catalogue이며, 경계는 Delporte(1930)의 IAU 공식 경계를 J2000으로 세차보정한
것입니다. 전체 고지는 `public/data/LICENSE.txt`를 참고하세요.

하나의 출처만 쓴 것은 라이선스 편의 때문만이 아닙니다. 별과 별자리선의 좌표가
이미 정합돼 있어, 선이 별에서 몇 각분 떨어져 나가는 문제가 구조적으로 생기지
않습니다(전처리 시 스냅 실패 0건).

천문 계산은 [astronomy-engine](https://github.com/cosinekitty/astronomy),
손 인식은 [MediaPipe Tasks Vision](https://github.com/google-ai-edge/mediapipe)
(Apache-2.0), UI 모션은 [Motion](https://motion.dev)(구 Framer Motion, MIT)이 담당합니다.

Motion은 **몰입 라우트에만** 들어갑니다. 홈 페이지 페이로드는 191 KB gzip으로 변화가
없고, 손 인식 화면을 여는 순간 three.js·astronomy-engine과 같은 동적 청크로 함께
로드됩니다. 60fps로 도는 부분(별 렌더·손 추적·카메라 자세)은 Motion을 거치지 않습니다 —
그쪽은 React 리렌더를 의도적으로 피해 ref로 직접 돌리며, 애니메이션 라이브러리를
끼우면 오히려 느려집니다. Motion이 맡는 건 시트 드래그, 패널 등장/퇴장, 탭 피드백처럼
**손가락이 직접 끄는 것들**입니다.

## 구조

```
app/
  (marketing)/     헤더·푸터 있는 일반 페이지 — 홈, 소개
  (immersive)/     크롬 없는 전체화면 라우트 — /sky/
  globals.css      모든 디자인 토큰과 타입 티어
components/sky/    항해 화면 전부 (SkyExperience가 오케스트레이터, WorldMap이 위치 지도)
components/home/   홈 — 히어로, 인터랙티브 별밭(초신성·유성)
lib/
  sky.ts           좌표 변환 — 천문의 중심
  gestures.ts      랜드마크 → 제스처 (순수 함수)
  constellationLore.ts  88개 별자리 설명 (계산할 수 없는 것만)
  useHandTracking  카메라 + MediaPipe 루프
  picking.ts       조준 → 별 선택
  cities.ts        146개 도시 (rank로 라벨 우선순위)
  land.ts          Natural Earth 대륙 윤곽 로더
scripts/           데이터 전처리 + 검증 2종
```

라우트 그룹을 쓴 것은 벤치마크 프로젝트와의 의도적인 차이입니다. 전체화면 몰입
화면에서는 모든 픽셀과 안전영역 인셋이 중요하고, 몰입 레이아웃이 자신의 뷰포트 메타와
오버스크롤 동작을 직접 소유해야 합니다.

## 배포

GitHub Pages 정적 내보내기입니다. `main`에 푸시하면
`.github/workflows/deploy.yml`이 `NEXT_PUBLIC_BASE_PATH=/explorer`로 빌드합니다.
전부 클라이언트 사이드라 정적 내보내기와 완전히 호환되며, Pages는 기본이 HTTPS라
카메라 권한 요구사항을 그대로 만족합니다.
